# Programming Assignment 1 — Flows in Networks

Solutions in Python 3 for the Coursera *Advanced Algorithms and Complexity* Programming Assignment 1:

- `evacuation`: maximum flow using Edmonds–Karp.
- `airline_crews`: maximum bipartite matching with augmenting paths.
- `stock_charts`: minimum chain cover via bipartite matching.

Each problem directory contains the submission source file and the provided local tests.
